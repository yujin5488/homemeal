# homemeal · 오늘의 집밥

남아있는 재료로 냉털하기!

냉장고에 있는 재료를 넣으면, 지금 바로 만들 수 있는 집밥 메뉴와 1~2개만 사면 되는 메뉴를 골라 주는 웹앱이에요.

## 지금 되는 것

- **냉장고**: 재료 넣기(버튼/직접 입력), 유통기한 적기, 곧 상하는 재료 알림, 집에 있는 양념, 못 먹는 재료
- **추천 메뉴**: 기본 레시피 38개 중에서 조건(인분, 시간, 실력, 스타일, 조리도구)에 맞게 추천, 인분에 맞춰 재료 양 계산
- **장보기**: 없는 재료 담기, 산 것 냉장고로 옮기기, 사 두면 쓸모 많은 재료 추천
- 입력한 내용은 지금 쓰는 브라우저에만 저장돼요(localStorage).

> 사진으로 재료 인식하기, Claude에게 새 레시피 받기는 claude.ai 아티팩트 안에서만 돼요.
> 이 사이트에서는 그 버튼이 숨겨지고, 나머지는 다 동작해요. 배포 단계에서 연결할 예정이에요.

## 파일 구성

```
집밥시작.bat     윈도우에서 더블클릭으로 켜기
tools/start.ps1  위 실행 파일이 하는 일 (최신 코드 받기, 서버 켜기)
index.html      화면 뼈대
css/style.css   디자인 (밝은/어두운 모드)
js/data.js      재료 목록과 기본 레시피 38개
js/ai.js        Claude 연결 창구 (지금은 claude.ai 안에서만 동작)
js/app.js       추천 계산, 화면 그리기, 저장
```

빌드 과정이 없는 순수 HTML/CSS/JS라서, 파일을 그대로 올리면 바로 웹사이트가 돼요.

## 내 컴퓨터에서 열어 보기 (윈도우)

**처음 한 번만**
1. 파이썬을 설치해요: https://www.python.org/downloads/ (설치 첫 화면에서 **Add python.exe to PATH** 체크)
2. 이 저장소를 ZIP으로 받아 원하는 곳(예: 바탕화면)에 압축을 풀어요.

**그다음부터는**
- 폴더 안의 **`집밥시작.bat`** 을 더블클릭하면 끝이에요.
  - GitHub에서 최신 코드를 알아서 받아 와요. 다시 다운로드할 필요 없어요.
  - 브라우저에 http://localhost:8088 이 열려요.
  - 검은 창을 닫으면 앱도 꺼져요.
- 인터넷이 안 되면 지금 있는 파일로 그냥 열어요.
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 눌러요.
- 냉장고 내용은 브라우저에 저장돼서, 같은 브라우저로 열면 그대로 남아 있어요.

**맥이나 다른 컴퓨터에서는** 폴더에서 터미널을 열고 `python3 -m http.server 8088` 을 실행한 뒤 http://localhost:8088 을 열어요.
